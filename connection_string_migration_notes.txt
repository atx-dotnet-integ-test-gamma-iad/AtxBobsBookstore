POSTGRESQL CONNECTION STRING REQUIREMENTS
================================================================================

Required Parameters:
--------------------
1. Host: Database server hostname or IP address
   - Example: mydb.us-east-1.rds.amazonaws.com
   - Required: Yes

2. Port: Database server port
   - Default: 5432
   - Required: Recommended (explicit specification)

3. Database: Target database name
   - Example: postgres, bobsbookstore
   - Required: Yes

4. Username: Database authentication username
   - Example: postgres, admin
   - Required: Yes

5. Password: Database authentication password
   - Required: Yes

Optional Parameters (Available in Npgsql):
------------------------------------------
- SSL Mode: Encryption mode (Disable, Allow, Prefer, Require)
- Timeout: Connection timeout in seconds
- Command Timeout: Command execution timeout
- Pooling: Connection pooling enabled/disabled
- Minimum Pool Size: Minimum connections in pool
- Maximum Pool Size: Maximum connections in pool
- Trust Server Certificate: Skip certificate validation (not recommended)

Example Connection Strings:
---------------------------

Basic PostgreSQL Connection:
Host=localhost;Port=5432;Database=postgres;Username=admin;Password=secretpass

PostgreSQL with SSL:
Host=mydb.us-east-1.rds.amazonaws.com;Port=5432;Database=postgres;Username=admin;Password=secretpass;SSL Mode=Require

PostgreSQL with Connection Pooling:
Host=mydb.us-east-1.rds.amazonaws.com;Port=5432;Database=postgres;Username=admin;Password=secretpass;Pooling=true;Minimum Pool Size=0;Maximum Pool Size=100

================================================================================
AWS SECRETS MANAGER SECRET FORMAT
================================================================================

Required Secret JSON Structure:
--------------------------------
{
  "host": "database-hostname.rds.amazonaws.com",
  "port": 5432,
  "username": "postgres",
  "password": "database-password",
  "dbInstanceIdentifier": "database-instance-id",
  "engine": "postgres"
}

Notes:
------
- Property names are case-insensitive (JsonSerializerOptions.PropertyNameCaseInsensitive = true)
- "host" maps to DbSecrets.Host
- "port" maps to DbSecrets.Port
- "username" maps to DbSecrets.Username
- "password" maps to DbSecrets.Password
- "dbInstanceIdentifier" and "engine" are metadata (not used in connection string)

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

Connection Failures:
--------------------
Issue: "Failed to read secret {secretId}"
Solution: 
- Verify IAM permissions for Secrets Manager access
- Confirm secret ARN is correct in appsettings.json
- Check AWS credentials configuration

Issue: "Failed to parse content for secret {secretId}"
Solution:
- Verify secret JSON structure matches DbSecrets schema
- Ensure required properties (host, port, username, password) are present
- Check for JSON syntax errors in secret content

Issue: "Connection refused" or "Timeout"
Solution:
- Verify database server is accessible from application host
- Check security group rules allow inbound traffic on PostgreSQL port (5432)
- Confirm database server is running
- Verify host and port values in secret are correct

Authentication Failures:
------------------------
Issue: "Password authentication failed"
Solution:
- Verify username and password in Secrets Manager are correct
- Confirm database user exists and has appropriate permissions
- Check if user account is locked or expired

SQL Execution Failures:
-----------------------
Issue: Stored procedure not found
Solution:
- Verify stored procedures migrated to PostgreSQL functions
- Confirm schema qualification (bobsbookstore_dbo.functionName)
- Check function exists in target database

Issue: Date/time function errors
Solution:
- Verify date function conversions (FORMAT→TO_CHAR, DATEDIFF→AGE, etc.)
- Check date/time format strings for PostgreSQL compatibility
- Test date functions independently to isolate issues
