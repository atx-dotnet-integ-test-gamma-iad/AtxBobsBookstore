DMS Tool Output:
----------------
{
  "conversion_timestamp": "2026-02-11T19:05:03.652035",
  "status": "error",
  "error": "Metadata model creation failed: {'error': 'Unknown metadata model creation status: RECEIVED'}",
  "error_timestamp": "2026-02-11T19:05:07.830950"
}

Manual Conversion Applied:
--------------------------
PostgreSQL Equivalent:
SELECT 
    BusinessEntityID, 
    TO_CHAR(ModifiedDate, 'YYYY-MM-DD HH24:MI:SS') AS FormattedModifiedDate, 
    DATE_PART('year', AGE(CURRENT_TIMESTAMP, BirthDate)) AS Age 
FROM bobsbookstore_dbo.author 
WHERE DATE_PART('year', HireDate) = @HireDate;

Conversion Method: MANUAL_AFTER_DMS_FAILURE
Conversion Notes:
- FORMAT() converted to TO_CHAR() with PostgreSQL format patterns
  * 'yyyy-MM-dd HH:mm:ss' → 'YYYY-MM-DD HH24:MI:SS'
- DATEDIFF(YEAR, BirthDate, GETDATE()) converted to DATE_PART('year', AGE(CURRENT_TIMESTAMP, BirthDate))
  * GETDATE() → CURRENT_TIMESTAMP
  * DATEDIFF for year difference → DATE_PART with AGE function
- DATEPART(YEAR, HireDate) converted to DATE_PART('year', HireDate)
- Schema and table names remain unchanged: bobsbookstore_dbo.author
- Parameter @HireDate remains unchanged (compatible with NpgsqlParameter)
